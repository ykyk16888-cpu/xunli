# 旬曆

> 每種食材，都有它的最佳時節

旬曆是一個查詢台灣當季食材的手機網頁 App，收錄蔬菜、水果、海鮮共 167 種。可以加到手機主畫面當 App 使用，沒有網路也能開。

起因是最近常有進口蔬菜「洗產地」的新聞。買菜時先查一下現在是不是產季，看到不是產季卻大量又便宜的商品，就知道要多看一眼產地標示。

---

## 功能

### 這個月
- 左右滑動切換月份，列出當月當季的食材，本月有紅點標記。
- 「新進場」「快下市」：這個月才開始有的，以及下個月就沒有的食材。
- 可以只看「全部／蔬菜／水果／海鮮」其中一類。
- 「只看季節限定」：把全年都有的食材收起來，畫面比較清爽。
- 搜尋名稱，也能用常見別名找，例如輸入「蚵仔」會找到牡蠣，「花椰菜」會找到青花菜。

### 詳細卡片
點食材名稱會跳出卡片，內容有：
- 12 個月的產季條
- **挑**：怎麼挑新鮮的
- **洗**：怎麼清洗（海鮮改成「處理」：吐沙、去內臟、挑腸泥等）
- **存**：回家怎麼保存
- **禁**：海鮮的禁漁期提醒（櫻花蝦、花蟹、三點蟹）
- 「加入採買」按鈕

### 採買清單
- 每一項依今天的月份，自動標示「當季／下月下市／非產季／養殖」。
- 勾選代表已經買到，點菜名可以展開挑、洗、存。
- 「分享」可以直接傳到 LINE。不支援分享選單的瀏覽器會改成複製。

### 掃碼查產地
- 拍下包裝上的 QR Code，或從相簿選照片辨識。
- 自動判斷是否為政府追溯網站（網址以 `gov.tw` 結尾）。不是的話會顯示警示。
- 掃出來是一串號碼時，可以複製號碼，再到產銷履歷網站查詢。
- 提供核對項目：品名、產地／生產者、日期、驗證機構、有效期限。
- 產季檢查：輸入菜名，看本月是不是產季。

## 部署

只要把所有檔案放在網站的同一層資料夾即可，不需要建置步驟。以下兩種方式擇一。

### 方式 A：Cloudflare Pages 連結這個儲存庫（建議）
儲存庫設成私有也可以用，之後只要更新 GitHub 上的檔案，網站就會自動更新。

1. 登入 Cloudflare，進入 **Workers & Pages** → **建立** → **Pages** → **連結 Git（Connect to Git）**。
2. 授權 GitHub，選擇這個儲存庫。
3. 建置設定：Framework preset 選 **None**，Build command **留空**，Build output directory 填 **`/`**。
4. 按 **儲存並部署**，完成後會得到 `專案名稱.pages.dev` 的網址。

### 方式 B：GitHub Pages
免費帳號的儲存庫必須設成 **公開**。

1. 儲存庫 → **Settings** → **Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
3. 等一兩分鐘，網址會是 `https://帳號名稱.github.io/儲存庫名稱/`。

## 加到手機主畫面

- **iPhone**：用 **Safari** 打開網址 → 分享鈕 →「加入主畫面」。
- **Android**：用 **Chrome** 打開網址 → 右上角 ⋮ →「安裝應用程式」或「加到主畫面」。

第一次打開時要連網，之後沒有網路也能使用。只有「開啟官方查詢」這類連到外部網站的功能需要網路。

---

## 更新方式

1. 用新版檔案覆蓋儲存庫裡的舊檔案。
2. 有改 `index.html` 時，請把 `sw.js` 第 3 行的版本號加一，例如 `"v5"` 改成 `"v6"`。
3. 手機下次連網打開 App 時會自動換成新版，採買清單會保留。

## 資料來源與說明

- **蔬菜（98 種）**：依《菜市場的一年》目錄的產季資料，重新整理成按月份排列。
- **水果（34 種）、海鮮（35 種）**：綜合農業部農業知識入口網、基隆市政府當季海鮮介紹、漁業署禁漁規定，以及媒體報導整理。各來源說法不完全一致，**僅供參考**。
- 挑選、清洗、保存提示依一般常見做法整理。
- 表上的月份是「盛產期」。高山或溫室栽培也會讓非產季出現台灣貨，所以非產季看到某種食材**不代表一定是進口**，比較適合當成多看一眼的訊號，再搭配產銷履歷、有機標章或追溯 QR Code 判斷。
- 掃碼功能只能確認標籤是否有在政府系統登記，無法證明包裝內的商品就是標籤上的那一批。
